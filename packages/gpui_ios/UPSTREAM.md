# Upstream

Copied from Zed's `crates/gpui_ios` (Apache-2.0) at
`5adae449a366fd8f8f87d983287d95eab37e9488` (https://github.com/zed-industries/zed), imported unmodified in [#7](https://github.com/xinnjie/zed-markdown-swift/pull/7).

This repository owns this copy and may deviate from upstream on purpose. Upstream is a reference for
fixes and ideas; review upstream changes and port them selectively instead of merging mechanically.

The root `Cargo.toml` (generated by `scripts/sync_zed_workspace.py`) provides Zed's workspace dependency
table and a `[patch]` that routes every Zed crate's `gpui_ios` dependency here.

`LICENSE-APACHE` is a regular file here (a copy of Zed's repository-root `LICENSE-APACHE`), because
upstream's is a symlink to the repository root.

## Changes for the hosted mode

Added in [#8](https://github.com/xinnjie/zed-markdown-swift/pull/8); not proposed upstream.

- `src/ios/platform.rs`: `IosPlatform::new_hosted` (no `UIApplication` run loop, the launch callback
  runs immediately) and `set_next_window_host_view`.
- `src/ios/application.rs`: hosted startup path that skips creating the `UIApplication`.
- `src/ios/window.rs`: a hosted window adds its Metal view to an embedder-owned `UIView` instead of
  creating a `UIWindow`, follows the host's size in `layoutSubviews`, and attaches its own display
  link to the main run loop.
- `Cargo.toml`: dropped `crate-type = ["staticlib"]`, the example, the test and their dev-dependencies.
  `examples/` and `tests/` are removed.

To update: re-copy upstream's `crates/gpui_ios`, re-apply the changes above, and run `scripts/sync_zed_workspace.py <zed-checkout>`.
