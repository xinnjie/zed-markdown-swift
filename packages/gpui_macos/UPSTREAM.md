`LICENSE-APACHE` is a regular file here (a copy of Zed's repository-root `LICENSE-APACHE`), because
upstream's is a symlink to the repository root.

## Changes for the hosted mode

- `src/window/hosted.rs` (new): `MacWindow::open_hosted` adds a `GPUIView` to an embedder-owned
  `NSView` instead of creating an `NSWindow`, and forwards the host window's key, occlusion and
  screen notifications to the existing delegate handlers.
- `src/platform.rs`: `MacPlatform::new_hosted` (no `NSApplication.run`, the launch callback runs
  immediately) and `set_next_window_host_view`.
- `src/window.rs`: `MacWindowState.hosted`; content size, bounds and mouse positions use the view's
  frame inside the host window; window-level operations (title, fullscreen, resize, tabs,
  accessibility) are no-ops for hosted windows; a hosted view takes first responder on click and
  only handles key equivalents while focused; the view class answers `acceptsFirstResponder`.
- `src/events.rs`: `platform_input_from_native` takes the view's origin in window coordinates
  along with its height.

To update: re-copy upstream's `crates/gpui_macos`, re-apply the changes above, and run
`scripts/sync_zed_workspace.py <zed-checkout>`.
